Guide for Event Organizers

How to Create a Catalog with hamp

This guide covers catalog-only use—publishing an existing participant list without using hamp's circle application form. You will create an event page, import your participating-circle list and circle-cut images, and publish an easy-to-browse web catalog for attendees. Here, “circle” means an exhibitor or creator group, and a “circle cut” is the image used for that circle's catalog entry.

View the Steps

Interface language: The current hamp interface and all screenshots in this guide are in Japanese. Look for the Japanese text shown first in each instruction; its English meaning follows in parentheses. For example: 「イベント作成・管理」 (Create / Manage Events). After publishing the catalog, request activation URLs so each participating circle can edit its own information. hamp staff must approve these URLs before they can be issued.

1

Create an Event

Sign in to hamp, then create the event page that will contain your catalog.

Where to click

  1. 「hampトップ」 (hamp Home)
  2. 「イベント作成・管理」 (Create / Manage Events)
  3. 「イベントを作成する」 (Create an Event)
  4. 「同人即売会」 (Doujinshi Sales Event)
  1. Sign in to hamp.
  2. On the hamp home page, select 「イベント作成・管理」 (Create / Manage Events).
  3. On the event management screen, select 「イベントを作成する」 (Create an Event).
  4. Under event type, select 「同人即売会」 (Doujinshi Sales Event).
  5. Choose 「単独の主催」 (Standalone Event) or 「親子型の主催」 (Parent–Child Event Structure), depending on how your event is organized.
  6. Enter the 「タイトル・イベント名」 (Title / Event Name).
  7. For 「URL末尾」 (URL Slug), enter at least three half-width letters, numbers, hyphens, or underscores.
  8. Review the information, then select 「作成」 (Create).

Example: 「イベントを作成する」 (Create an Event) opened from the event management screen

Choosing 「単独の主催」 (Standalone Event) or 「親子型の主催」 (Parent–Child Event Structure)

Choose 「単独の主催」 (Standalone Event) when one event has one event name and one catalog.

Choose 「親子型の主催」 (Parent–Child Event Structure) when a joint event contains multiple themed or “only” events and you want each catalog displayed on a separate tab.

What Is 「URL末尾」 (URL Slug)?

This is the text used at the end of the event page URL. For example, if you enter nihonsousaku2026, that text becomes the final part of the event page URL.

Do not use Japanese characters or spaces. Use half-width letters, numbers, hyphens, and underscores only.

2

Enter the Event's Basic Settings

After creating the event, open 「基本設定」 (Basic Settings) from 「即売会トップ」 (Sales Event Home) in event management, then enter the information attendees will see.

  1. In event management, open 「即売会トップ」 (Sales Event Home) for the event you want to edit.
  2. From the menu, open 「基本設定」 (Basic Settings).
  3. Complete every item required for publication. Add optional information as needed.
  4. Select 「更新して保存」 (Update and Save).
  5. When you are ready to make the event publicly visible, change its visibility from 「非公開」 (Private) to 「公開」 (Public), then select 「更新して保存」 (Update and Save) again.

Example: the current 「基本設定」 (Basic Settings) screen. Green and red labels identify fields needed for publication.

Fields Required for Publication

These fields are marked 「必須」 (Required) or 「一般公開に必要」 (Required for Public Release) on the screen.

「トップ画像」 (Main Image) 「公開に必要」 (Required for Public Release)
A landscape image displayed at the top of the event page. A 16:9 image at 1080p to 4K is recommended.
「サムネイル」 (Thumbnail) 「公開に必要」 (Required for Public Release)
A square image displayed in event listings and similar locations. Approximately 1,000 px square is recommended.
「イベント名」 (Event Name) 「必須」 (Required)
Enter the event's official name exactly as you want attendees to see it.
「URL末尾」 (URL Slug) 「必須」 (Required)
This is used in the event page URL. Enter at least three half-width letters, numbers, hyphens, or underscores.
「簡単な説明」 (Short Description) 「公開に必要」 (Required for Public Release)
Enter a short sentence that clearly tells attendees what the event is about.
「ジャンルタグ」 (Genre Tags) 「必須」 (Required)
Add at least one genre that fits the event. You can add up to ten.
「開催日時・場所」 (Date, Time, and Location) 「必須」 (Required)
Set the event date, timetable, venue name, and address.

Fields to Set as Needed

Add these according to how your event will operate and what attendees need to know.

「イベント名（読み）」 (Event Name Reading) 「任意」 (Optional)
Enter the event name's reading in hiragana or katakana.
「詳細説明」 (Detailed Description)
Select 「詳細説明を編集」 (Edit Detailed Description) and add complete event guidance.
「タイムライン」 (Timeline)
If you will use the timeline for this event, set it to 「有効」 (Enabled).
「配置図」 (Venue Layout)
Select 「配置図エディタを開く」 (Open Layout Editor) to create or edit the venue layout.
「リンクの一括設定」 (Bulk Link Settings)
Enter URLs shared by all child events, such as the event website, X account, circle application form, and ticket sales page. Enter event-specific links in each child event's settings.
3

Download the Circle-List Template

Download the template used to register participating circles.

  1. On the event management screen, open 「参加サークル」 (Participating Circles).
  2. Under 「hamp外イベント用テンプレート」 (Template for Events Outside hamp), select 「EXCELテンプレートをDL」 (Download Excel Template).
  3. Open the downloaded file.

If You Use Numbers on a Mac

Select 「CSV形式でダウンロード」 (Download as CSV) before downloading the template.

Do not translate, rename, or delete the Japanese column names in the template's header row. hamp uses those exact headings when importing the file.

Rules for Entering Space Codes

  • Always place a half-width hyphen - between the block name and space number.
  • Valid entries include A-01, あ-2, その他-01, and デジタル-02. Japanese block names are accepted.
  • Suffixes such as あ-01a and A-01b are supported.
  • For two spaces, enter a half-width comma , between the space numbers, as in あ-01,02.
  • For two spaces distinguished by the suffixes in あ-01a and あ-01b, enter あ-01ab.

5

Upload the Circle List

After completing the template, save it and upload it to hamp.

  1. Save the completed template.
  2. On the hamp event management screen, open 「参加サークル」 (Participating Circles).
  3. Select 「サークル追加」 (Add Circles) to open 「サークルリストアップロード」 (Circle List Upload).
  4. Select 「TSV/Excel/Numbersファイルを選択」 (Choose a TSV/Excel/Numbers File), then choose the template you saved.
  5. Choose 「リストへの追加」 (Add to List) to keep the existing list, or 「リストの置換」 (Replace List) only when you intend to replace the entire list.
  6. Select 「アップロード」 (Upload).
  7. Wait until the upload finishes before leaving the page.

After the upload, the imported circles appear in the circle list. Confirm that 「状態」 (Status) shows OK for every circle.

If a Circle List Already Exists

OptionWhen to Use It
「リストの置換」 (Replace List)Use this to delete the entire current list and replace it with a new one.
「リストへの追加」 (Add to List)Use this to keep the current list and add only new circles.

If you are unsure, use 「リストへの追加」 (Add to List). Use 「リストの置換」 (Replace List) only when you intend to re-import all circle information.

6

Upload Circle-Cut Images

If you will register circle-cut images, do this after uploading the circle list.

  1. On the event management screen, open 「参加サークル」 (Participating Circles).
  2. Select 「カット」 (Cuts).
  3. On 「サークルカット管理」 (Circle Cut Management), open 「一括アップロード」 (Bulk Upload).
  4. Drag a ZIP file or folder onto 「ZIPファイルまたはフォルダをドロップ」 (Drop a ZIP File or Folder). To choose a folder through a dialog instead, select 「フォルダ選択」 (Choose Folder).
  5. Follow the on-screen confirmation and wait for the upload to finish.

Match the File Names Exactly

If you entered cut01 in the template, name the corresponding image cut01.png or cut01.jpg.

Images may also be linked when their names match the circle or creator name, but simple identifiers such as cut01 and cut02 reduce mistakes.

7

Apply the Data to the Live Site and Check the Public Page

After registering the circle list and circle-cut images, complete both publishing controls—apply the latest data to the live site and publish the circles—then check exactly what attendees will see.

  1. On the event management screen, open 「参加サークル」 (Participating Circles).
  2. Confirm that each circle's status is OK.
  3. Select 「本番反映」 (Apply to Live Site), then confirm that it changes to 「反映済み」 (Applied to Live Site).
  4. Set 「サークル公開」 (Publish Circles) to 「公開」 (Public).
  5. Confirm both states at the same time: 「反映済み」 (Applied to Live Site) and 「公開」 (Public). A circle status of OK alone does not publish the catalog.

If You Need to Change the Block Order

From 「参加サークル」 (Participating Circles) on the event management screen, open 「ブロック」 (Blocks). After changing the order, select 「変更を保存」 (Save Changes).

  1. On the event management screen, select 「公開ページへ」 (View Public Page).
  2. Confirm that the circle list appears on the public page.
  3. Check every circle's name, creator name, space assignment, and circle cut.
  4. Check that the circles appear in the intended order.

If you change circle information later, review the change, select 「本番反映」 (Apply to Live Site) again, and recheck the public page.

8

Request Activation URLs

Once the catalog is published, prepare to let each participating circle edit its own information.

  1. Confirm both publishing states: 「公開」 (Public) and 「反映済み」 (Applied to Live Site).
  2. Use the official hamp inquiry form to request activation URLs. Include the event name and public-page URL so the team can identify the event.
  3. After hamp staff approve the request, receive the issued activation URLs.
  4. Send the correct activation URL to each participating circle so it can claim editing access to its own entry.

hamp Staff Approval Is Required

At present, hamp staff must approve activation URLs before they are issued. Follow the sharing instructions provided by hamp staff when sending the URLs to participating circles.

FAQ

Common Problems

Start with 「スペース」 (Space), 「サークル名」 (Circle Name), 「サークル名（カナ）ひらがな・カタカナ」 (Circle Name in Hiragana or Katakana), 「作家名」 (Creator Name), and 「作家名（カナ）ひらがな・カタカナ」 (Creator Name in Hiragana or Katakana). You can register the list without circle cuts or social-media links and add them later.

Confirm that the name in the 「サークルカット」 (Circle Cut) column matches the image file name. Also check that the image is not inside a nested folder and that the same image name is not used for more than one circle.

If you only need to add a few circles, use 「リストへの追加」 (Add to List). Use 「リストの置換」 (Replace List) only when you intend to re-import all circle information.

A child event corresponds to one catalog tab. For example, if a joint event contains several differently named sales events at the same venue on the same day, create two or more child events to give each one its own catalog tab. Every event must have at least one child event.

Confirm that you completed both 「本番反映」 (Apply to Live Site) and 「サークル公開」 (Publish Circles). Even if each circle's status is OK, the circle list will not appear on the public page until both steps are complete.
