주최자용 가이드

hamp에서 카탈로그 만드는 방법

hamp의 서클 참가 신청 폼은 사용하지 않고, 이미 가지고 있는 참가자 명단으로 카탈로그만 공개하는 방법을 설명합니다. 이벤트 페이지를 만들고 참가 서클 목록과 서클 컷을 등록한 뒤, 참가자가 보기 편한 웹 카탈로그를 공개하기까지 순서대로 안내합니다. 여기서 ‘서클’은 창작자·출전자 팀을, ‘서클 컷’은 카탈로그에 표시되는 대표 이미지를 뜻합니다.

절차 보기

화면 언어 안내: 현재 hamp의 화면과 이 가이드의 스크린샷은 일본어로 표시됩니다. 각 단계에서는 화면에서 찾아야 할 정확한 일본어를 먼저 쓰고, 그 뒤에 한국어 뜻을 덧붙였습니다. 예: 「イベント作成・管理」(이벤트 생성·관리). 실제 화면에서는 앞쪽의 일본어를 찾아 주세요. 카탈로그 공개 후에는 「アクティベートURL」(활성화 URL)을 발급하여 서클 참가자에게 편집 권한을 부여하며, 발급에는 hamp 운영팀의 승인이 필요합니다.

사전 준비

먼저 준비할 것

입력 화면에서 헤매지 않도록 아래 정보를 미리 준비해 두세요. 아직 정해지지 않은 내용은 나중에 수정할 수 있습니다.

01

이벤트명

예: 日本創作イベント2026(일본어 이벤트명 예시)

02

개최 날짜·시간

개최일, 시작 시간, 종료 시간

03

행사장 정보

행사장 이름과 주소. 온라인 행사라면 개최 방식을 준비합니다.

04

상단 이미지

이벤트 페이지 상단에 표시할 이미지입니다. 16:9 가로형 이미지를 권장합니다.

05

썸네일 이미지

이벤트 목록 등에 표시되는 정사각형 이미지입니다.

06

참가 서클 목록

Excel, Numbers, CSV 등으로 관리하고 있는 서클 목록입니다.

07

서클 컷 이미지

선택 사항입니다. 아직 모두 준비되지 않았다면 나중에 등록해도 됩니다.

진행 방법

위에서부터 차례대로 진행하세요. 카탈로그 제작부터 공개 후 편집 권한 부여까지의 전체 흐름입니다.

  5. 5서클 목록 업로드하기
  6. 6서클 컷 업로드하기
  7. 7운영 사이트에 반영하고 공개 페이지 확인하기
  8. 8활성화 URL 발급 요청하기

목차

1

이벤트 만들기

hamp에 로그인한 다음, 홈 화면에서 카탈로그를 게시할 이벤트 페이지를 만듭니다.

화면 이동 순서

  1. 「hampトップ」(hamp 홈)
  2. 「イベント作成・管理」(이벤트 생성·관리)
  3. 「イベントを作成する」(이벤트 만들기)
  4. 「同人即売会」(동인지 즉매회)
  1. hamp에 로그인합니다.
  2. hamp 홈 화면에서 「イベント作成・管理」(이벤트 생성·관리)를 누릅니다.
  3. 이벤트 관리 화면에서 「イベントを作成する」(이벤트 만들기)를 누릅니다.
  4. 이벤트 유형에서 「同人即売会」(동인지 즉매회)를 선택합니다.
  5. 이벤트 구성에 맞게 「単独の主催」(단독 이벤트) 또는 「親子型の主催」(상위·하위 이벤트 구조)를 선택합니다.
  6. 「タイトル・イベント名」(제목·이벤트명)을 입력합니다.
  7. 「URL末尾」(URL 끝부분)에 반각 영문자·숫자, 하이픈 또는 밑줄을 사용하여 3자 이상 입력합니다.
  8. 입력 내용을 확인한 뒤 「作成」(만들기)를 누릅니다.

화면 예시: 이벤트 관리 화면에서 「イベントを作成する」(이벤트 만들기)를 연 상태

「単独の主催」(단독 이벤트)와 「親子型の主催」(상위·하위 이벤트 구조)의 차이

단독 이벤트는 하나의 이벤트에 하나의 이벤트명과 하나의 카탈로그가 있을 때 선택합니다.

상위·하위 이벤트 구조는 합동 이벤트 안에 여러 온리 이벤트 등을 마련하고, 각 하위 이벤트의 카탈로그를 별도 탭으로 나누어 표시할 때 선택합니다.

「URL末尾」(URL 끝부분)란?

이벤트 페이지의 URL에 사용되는 문자열입니다. 예를 들어 nihonsousaku2026을 입력하면 이벤트 페이지 URL의 마지막 부분에 이 문자열이 들어갑니다.

일본어나 공백은 사용하지 말고, 반각 영문자·숫자, 하이픈, 밑줄을 사용해 주세요.

2

이벤트 기본 설정 등록하기

이벤트를 만든 뒤, 이벤트 관리의 「即売会トップ」(즉매회 홈)에서 「基本設定」(기본 설정)을 열어 참가자에게 보여 줄 정보를 등록합니다.

  1. 이벤트 관리에서 해당 이벤트의 「即売会トップ」(즉매회 홈)을 엽니다.
  2. 메뉴에서 「基本設定」(기본 설정)을 엽니다.
  3. 공개에 필요한 항목을 입력하고, 필요에 따라 선택 항목도 설정합니다.
  4. 「更新して保存」(업데이트하여 저장)을 누릅니다.
  5. 누구나 볼 수 있게 공개하려면 공개 상태를 「非公開」(비공개)에서 「公開」(공개)로 바꾼 뒤, 「更新して保存」(업데이트하여 저장)을 누릅니다.

화면 예시: 현재 「基本設定」(기본 설정) 화면. 공개에 필요한 항목은 초록색 또는 빨간색 라벨로 표시됩니다.

공개에 필요한 항목

화면에 「必須」(필수) 또는 「一般公開に必要」(일반 공개에 필요)라고 표시되는 항목입니다.

「トップ画像」(상단 이미지) 「公開に必要」(공개에 필요)
이벤트 페이지 상단에 표시되는 가로형 이미지입니다. 16:9 비율, 1080p~4K를 권장합니다.
「サムネイル」(썸네일) 「公開に必要」(공개에 필요)
이벤트 목록 등에 표시되는 정사각형 이미지입니다. 약 1000px 크기를 권장합니다.
「イベント名」(이벤트명) 「必須」(필수)
참가자에게 표시할 이벤트의 공식 명칭을 입력합니다.
「URL末尾」(URL 끝부분) 「必須」(필수)
이벤트 페이지 URL에 사용됩니다. 반각 영문자·숫자, 하이픈 또는 밑줄을 사용하여 3자 이상 입력합니다.
「簡単な説明」(간단한 설명) 「公開に必要」(공개에 필요)
이벤트 내용을 짧고 쉽게 알 수 있는 설명문을 입력합니다.
「ジャンルタグ」(장르 태그) 「必須」(필수)
이벤트에 맞는 장르를 1개 이상, 최대 10개까지 등록합니다.
「開催日時・場所」(개최 일시·장소) 「必須」(필수)
개최일, 시간표, 행사장 이름과 주소를 설정합니다.

필요에 따라 설정할 항목

이벤트 운영 방식과 안내 내용에 맞춰 추가로 설정합니다.

「イベント名（読み）」(이벤트명 읽는 법) 「任意」(선택)
히라가나 또는 가타카나로 입력합니다.
「詳細説明」(자세한 설명)
「詳細説明を編集」(자세한 설명 편집)을 눌러 이벤트의 상세 안내를 등록합니다.
「タイムライン」(타임라인)
이벤트에서 타임라인을 사용하려면 「有効」(활성화)로 설정합니다.
「配置図」(배치도)
「配置図エディタを開く」(배치도 에디터 열기)에서 행사장 배치도를 만들거나 수정합니다.
「リンクの一括設定」(링크 일괄 설정)
모든 자식 이벤트에서 공통으로 사용할 웹사이트, X, 서클 신청, 티켓 판매 URL을 입력합니다. 이벤트마다 다른 링크는 자식 이벤트 설정에 입력합니다.
3

서클 목록용 템플릿 다운로드하기

참가 서클을 등록할 때 사용할 템플릿을 다운로드합니다.

  1. 이벤트 관리 화면에서 「参加サークル」(참가 서클)을 엽니다.
  2. 「hamp外イベント用テンプレート」(hamp 외부 이벤트용 템플릿)에서 「EXCELテンプレートをDL」(EXCEL 템플릿 다운로드)를 누릅니다.
  3. 다운로드한 파일을 엽니다.

Mac에서 Numbers를 사용하는 경우

「CSV形式でダウンロード」(CSV 형식으로 다운로드)에 체크한 뒤 다운로드해 주세요.

템플릿 제목 행의 일본어 열 이름은 번역하거나 이름을 바꾸거나 삭제하지 마세요. hamp는 업로드할 때 이 정확한 열 이름을 사용합니다.

4

스페이스 번호 입력 규칙

  • 블록명과 스페이스 번호 사이에는 반드시 반각 하이픈 -을 넣어 주세요.
  • A-01, あ-2, その他-01, デジタル-02처럼 입력할 수 있습니다. 일본어 블록명도 사용할 수 있다는 예시입니다.
  • あ-01a나 A-01b처럼 뒤에 문자를 덧붙이는 표기에도 대응합니다.
  • 스페이스가 2개이면 あ-01,02처럼 스페이스 번호 사이에 반각 쉼표 ,를 넣습니다.
  • あ-01a와 あ-01b처럼 접미사가 붙은 스페이스 2개를 함께 사용할 때는 あ-01ab로 입력합니다.

템플릿의 「サークルカット」(서클 컷) 열에 이미지 파일명을 입력합니다.

템플릿 입력값

あめんぼcut01
あかいなcut02
hamp開発cut03

이미지 파일명

cut01cut01.png
cut02cut02.jpg

템플릿의 이름과 이미지 파일명이 일치하지 않으면 서클 컷이 올바르게 연결되지 않을 수 있습니다. 이미지는 하나의 폴더에 모으고, 그 폴더 안에 다른 하위 폴더를 만들지 마세요.

5

서클 목록 업로드하기

템플릿 입력을 마치면 파일을 hamp에 업로드합니다.

  1. 작성한 템플릿을 저장합니다.
  2. hamp 이벤트 관리 화면에서 「参加サークル」(참가 서클)을 엽니다.
  3. 「サークル追加」(서클 추가)를 눌러 「サークルリストアップロード」(서클 목록 업로드)를 엽니다.
  4. 「TSV/Excel/Numbersファイルを選択」(TSV/Excel/Numbers 파일 선택)을 누르고 앞에서 저장한 템플릿 파일을 선택합니다.
  5. 기존 목록을 유지하려면 「リストへの追加」(목록에 추가)를 선택합니다. 전체 목록을 완전히 교체할 때만 「リストの置換」(목록 바꾸기)를 선택하세요.
  6. 「アップロード」(업로드)를 누릅니다.
  7. 업로드가 끝날 때까지 기다립니다.

업로드가 끝나면 등록한 서클이 서클 목록에 표시됩니다. 목록의 「状態」(상태)가 OK인지 확인해 주세요.

이미 서클 목록이 등록되어 있는 경우

선택 항목사용할 때
「リストの置換」(목록 바꾸기)현재 목록을 모두 지우고 새 목록으로 완전히 교체할 때
「リストへの追加」(목록에 추가)현재 목록은 그대로 두고 새로운 서클만 추가할 때

어느 것을 선택해야 할지 모르겠다면 「リストへの追加」(목록에 추가)를 사용하세요. 「リストの置換」(목록 바꾸기)는 모든 서클 정보를 처음부터 다시 넣어야 할 때만 사용합니다.

6

서클 컷 업로드하기

서클 컷 이미지를 등록하려면 먼저 서클 목록 업로드를 끝낸 뒤 아래 절차를 진행합니다.

  1. 이벤트 관리 화면에서 「参加サークル」(참가 서클)을 엽니다.
  2. 「カット」(컷)을 누릅니다.
  3. 「サークルカット管理」(서클 컷 관리)에서 「一括アップロード」(일괄 업로드)를 엽니다.
  4. 「ZIPファイルまたはフォルダをドロップ」(ZIP 파일 또는 폴더 놓기) 영역에 ZIP 파일이나 폴더를 끌어다 놓습니다. 파일 선택 창에서 폴더를 고르려면 「フォルダ選択」(폴더 선택)을 누릅니다.
  5. 화면의 확인 절차에 따라 업로드가 끝날 때까지 기다립니다.

파일명을 정확히 맞추기

템플릿에 cut01을 입력했다면 이미지 파일명은 cut01.png 또는 cut01.jpg처럼 지정합니다.

서클명이나 작가명과 같은 파일명으로도 연결되는 경우가 있지만, 실수를 줄이려면 cut01, cut02처럼 단순하고 겹치지 않는 이름을 권장합니다.

7

운영 사이트에 반영하고 공개 페이지 확인하기

서클 목록과 서클 컷을 등록한 뒤, 최신 데이터를 운영 사이트에 반영하는 작업과 서클을 공개하는 작업을 모두 완료하고 참가자에게 실제로 보이는 페이지를 확인합니다.

  1. 이벤트 관리 화면에서 「参加サークル」(참가 서클)을 엽니다.
  2. 서클 목록의 「状態」(상태)가 OK인지 확인합니다.
  3. 「本番反映」(운영 사이트에 반영)을 누른 뒤 표시가 「反映済み」(운영 반영 완료)로 바뀌었는지 확인합니다.
  4. 「サークル公開」(서클 공개)를 「公開」(공개)로 설정합니다.
  5. 「反映済み」(운영 반영 완료)와 「公開」(공개)가 동시에 표시되는지 확인합니다. 서클의 「状態」(상태)가 OK인 것만으로는 카탈로그가 공개되지 않습니다.

블록 순서를 변경하려면

이벤트 관리 화면의 「参加サークル」(참가 서클)에서 「ブロック」(블록)을 엽니다. 순서를 변경한 뒤 「変更を保存」(변경 내용 저장)을 눌러 주세요.

  1. 이벤트 관리 화면에서 「公開ページへ」(공개 페이지로)를 누릅니다.
  2. 공개 페이지에 서클 목록이 표시되는지 확인합니다.
  3. 서클명, 작가명, 배치, 서클 컷이 올바른지 확인합니다.
  4. 표시 순서에 문제가 없는지 확인합니다.

나중에 서클 정보를 변경했다면 수정 내용을 확인한 뒤 「本番反映」(운영 사이트에 반영)을 다시 실행하고 공개 페이지를 확인해 주세요.

8

「アクティベートURL」(활성화 URL) 발급 요청하기

카탈로그 공개가 끝나면 서클 참가자가 자신의 정보를 직접 수정할 수 있도록 준비합니다.

  1. 「公開」(공개)와 「反映済み」(운영 반영 완료)가 모두 표시되는지 확인합니다.
  2. hamp 공식 문의 양식으로 「アクティベートURL」(활성화 URL) 발급을 요청합니다. 운영팀이 이벤트를 찾을 수 있도록 이벤트명과 공개 페이지 URL을 함께 적어 주세요.
  3. hamp 운영팀의 승인이 완료되면 발급된 활성화 URL을 받습니다.
  4. 서클 참가자에게 활성화 URL을 안내하여 각 참가자에게 편집 권한을 부여합니다.

발급에는 hamp 운영팀의 승인이 필요합니다

현재 「アクティベートURL」(활성화 URL)은 hamp 운영팀의 승인을 거쳐 발급됩니다. 참가 서클에 URL을 전달할 때는 hamp 운영팀이 안내하는 공유 방법을 따라 주세요.

자주 막히는 부분

먼저 「スペース」(스페이스), 「サークル名」(서클명), 「サークル名（カナ）ひらがな・カタカナ」(서클명·히라가나/가타카나), 「作家名」(작가명), 「作家名（カナ）ひらがな・カタカナ」(작가명·히라가나/가타카나)를 입력해 주세요. 서클 컷과 SNS 정보는 나중에 추가해도 되고, 비워 둔 상태로도 서클을 등록할 수 있습니다.

템플릿의 「サークルカット」(서클 컷) 열에 적은 이름과 실제 이미지 파일명이 일치하는지 확인해 주세요. 이미지가 폴더 안의 하위 폴더에 들어 있지는 않은지, 동일한 이미지명을 여러 서클에서 사용하지는 않았는지도 확인해 주세요.

일부 서클만 추가하려면 「リストへの追加」(목록에 추가)를 사용하세요. 모든 서클 정보를 새로 입력하여 완전히 교체할 때만 「リストの置換」(목록 바꾸기)를 사용합니다.

자식 이벤트는 카탈로그 탭 하나에 해당합니다. 예를 들어 같은 날 같은 행사장에서 이름이 다른 여러 즉매회를 함께 개최한다면, 자식 이벤트를 2개 이상 설정하여 각 카탈로그를 별도의 탭으로 만들 수 있습니다. 자식 이벤트는 반드시 1개 이상 설정해야 합니다.

「本番反映」(운영 사이트에 반영) 작업과 「サークル公開」(서클 공개) 작업이 모두 끝났는지 확인해 주세요. 서클 목록의 「状態」(상태)가 OK여도 이 두 작업을 완료하지 않으면 공개 페이지에 서클 목록이 표시되지 않습니다.
