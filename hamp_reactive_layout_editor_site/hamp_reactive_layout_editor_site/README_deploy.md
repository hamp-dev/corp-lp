# hamp リアクティブ配置図エディタ FAQサイト

## 内容
- faq_reactive_layout_editor.html: 追加するHTMLページ
- styles.css / script.js: ローカルプレビュー用。corp-lpに既存のものがある場合は既存ファイルを使えます。
- image/logo/logo.svg: ローカルプレビュー用のhampロゴ
- images/reactive-layout/*.jpg: 録画から切り出した操作説明用スクリーンショット

## デプロイ手順
1. corp-lpのルートに `faq_reactive_layout_editor.html` を追加します。
2. `images/reactive-layout/` を追加します。
3. 既存の `styles.css` と `script.js` を使う場合は、同名ファイルを上書きしないでください。
4. ブラウザで `/faq_reactive_layout_editor.html` を確認します。

## 注意
既存の配置図画像を使う場合は、スペース枠・番号・サークル名を一度消してから背景画像として読み込む説明にしています。
